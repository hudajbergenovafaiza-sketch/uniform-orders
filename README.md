# uniform-orders

Веб-система управления заявками на пошив униформы.

Клиенты (физлица и организации) оформляют заявки без регистрации: указывают изделия, размеры, количество и прикрепляют файлы (логотип, эскиз, Excel с размерами). Сотрудники и администратор швейного предприятия видят заявки, ведут их по статусам и управляют заказами. Система заменяет ручной учёт заявок и ускоряет их обработку.

> **Статус:** проектирование. Код ещё не написан, готова архитектура.

## Стек

- **Клиент:** React (Vite)
- **Сервер:** Node.js + Express
- **База данных:** PostgreSQL
- **ORM** (работа с базой через JavaScript): Prisma

## Основные возможности (MVP)

1. Форма заявки: «Физлицо / Организация», несколько изделий в одном заказе
2. Загрузка файлов к заявке
3. Ориентировочная стоимость при оформлении
4. Номер заявки и проверка статуса по **номеру + телефону**
5. Вход сотрудников и администратора
6. Список заявок: поиск, фильтр по статусу, пагинация
7. Карточка заявки: смена статуса, история изменений
8. Панель администратора: итоговая цена, назначение сотрудника, каталог, сотрудники

## Роли

| Роль | Доступ |
|---|---|
| Гость (клиент) | Оформление заявки, проверка статуса |
| Сотрудник | Просмотр заявок, скачивание файлов, смена статусов |
| Администратор | Всё выше, а также цены, назначения, каталог, сотрудники |
